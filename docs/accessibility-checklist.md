# Accessibility Checklist

Quick reference for common a11y patterns.

- [ ] Use semantic HTML (nav, main, aside)
- [ ] Add alt text to meaningful images
- [ ] Ensure color contrast ratio >= 4.5:1
- [ ] Label form inputs with visible labels
- [ ] Support keyboard navigation (focus visible)
- [ ] Announce dynamic content with aria-live
- [ ] Test with screen readers (NVDA, VoiceOver)

Add as needed — evolve with experience.
